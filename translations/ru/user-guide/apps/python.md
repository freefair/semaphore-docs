# Python

Semaphore может выполнять Python-скрипты напрямую. Для этого создайте шаблон задачи **Python**.

<a id="creating-a-python-template"></a>

## Создание шаблона Python

1. Перейдите в раздел **Шаблоны задач** и нажмите кнопку **Новый шаблон**.
2. Выберите **Python** в качестве типа приложения.
3. Настройте шаблон:

| Поле | Описание |
|---|---|
| **Название** | Понятное название шаблона |
| **Репозиторий** | Репозиторий, содержащий ваш `.py`-скрипт |
| **Playbook / Скрипт** | Относительный путь к скрипту, например `scripts/deploy.py` |
| **Группы переменных** | Группы переменных, значения которых передаются как переменные окружения |

4. Нажмите **Создать**.
5. Нажмите **Запустить**, чтобы выполнить шаблон.

<a id="passing-variables-to-scripts"></a>

## Передача переменных в скрипты

Переменные из выбранных **Групп переменных** передаются как переменные окружения. Обращайтесь к ним в Python через `os.environ`:

```python
import os

target = os.environ.get("TARGET_HOST")
print(f"Deploying to {target}")
```

<a id="python-version-and-dependencies"></a>

## Версия Python и зависимости

Semaphore использует тот бинарный файл `python3`, который находится в `PATH` в среде выполнения.

- **Установка из бинарного файла/пакета**: убедитесь, что на хосте установлен нужный `python3`.
- **Docker**: используйте собственный образ с требуемой версией Python.
- **Docker (дополнительные пакеты)**: смонтируйте `requirements.txt` по пути `/etc/semaphore/requirements.txt` в контейнере сервера или runner’а. Semaphore устанавливает его во встроенное виртуальное окружение Python при каждом запуске контейнера. См. [Установка дополнительных зависимостей Python](../../../../docs/admin-guide/installation/docker.md#installing-additional-python-dependencies).

<a id="notes"></a>

## Примечания

- Скрипты выполняются в неинтерактивном режиме.
- Код выхода `0` означает успех; любой ненулевой код выхода помечает задачу как неудачную.
