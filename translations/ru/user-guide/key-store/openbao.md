# Хранилище секретов OpenBao

Semaphore UI поддерживает [OpenBao](https://openbao.org) в качестве хранилища секретов.

OpenBao — это open-source-форк HashiCorp Vault с совместимым API, поэтому хранилище работает точно так же, как [хранилище HashiCorp Vault](../../../../docs/user-guide/key-store/hashicorp-vault.md).

Вы можете указать следующие параметры:
- **Server URL** — адрес вашего сервера OpenBao.
- **Mount** — путь монтирования движка секретов KV v2 (по умолчанию `secret`).
- **Namespace** — пространство имён OpenBao (v2.3+), необязательно.
- **Token** — токен аутентификации. Токен может быть:
    - Сохранён в базе данных.
    - Передан через переменную окружения.
    - Передан через файл.
> **Warning**
>
> Если токен берётся из **файла**, этот файл должен находиться **внутри** каталога секретов, который использует Semaphore. Настройте этот каталог с помощью `dirs.secrets` или переменной окружения `SEMAPHORE_SECRETS_PATH`. Устаревший параметр верхнего уровня `secrets_path` по-прежнему принимается для старых конфигураций. Если ничего не задано, по умолчанию используется `/tmp/semaphore`. Подробнее о приоритетах см. [Каталог секретов](../../../../docs/admin-guide/configuration/config-file.md#secrets-directory).

Хранилище может работать в режиме «только чтение».

<a id="how-to-use"></a>

## Как использовать

1. В вашем проекте откройте **Хранилище ключей** → **Хранилища** и создайте новое хранилище **OpenBao** (URL, путь монтирования и токен).
2. При создании или редактировании ключа в хранилище ключей выберите ваше хранилище OpenBao в качестве типа хранилища.
3. Укажите путь к секрету в OpenBao, по которому должны храниться учётные данные.

<a id="syncing-secrets"></a>

## Синхронизация секретов

Секреты, хранящиеся в OpenBao, можно автоматически импортировать в хранилище ключей и поддерживать в актуальном состоянии, так же как и с другими внешними хранилищами. См. [Синхронизация секретов из удалённых хранилищ](../../../../docs/user-guide/key-store/secret-sync.md).

<a id="variable-groups"></a>

## Группы переменных

OpenBao также можно использовать как хранилище для [групп переменных](../../../../docs/user-guide/environment.md). При редактировании группы переменных выберите ваше хранилище OpenBao в качестве типа хранилища и укажите путь к папке, в которой будут храниться секреты.
