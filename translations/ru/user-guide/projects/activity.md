# Активность

Страница «Активность» предоставляет полный журнал аудита всех действий и событий, происходящих в вашем проекте. Эта функция отслеживает действия пользователей и системные события, давая вам полную картину того, что происходит в проекте.

![](../../../../static/assets/project_activity.webp)

<a id="overview"></a>

## Обзор

Страница «Активность» отображает хронологическую ленту всех событий проекта, включая:

- Действия пользователей (создание, редактирование, удаление ресурсов)
- Системные события и уведомления
- Изменения доступа и прав
