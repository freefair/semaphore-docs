# Referência

Esta seção é para o momento em que você já sabe o que quer e precisa do nome, do tipo ou
do valor padrão exatos. Ela explica o mínimo possível; disso cuidam os guias.

Duas das páginas daqui são **geradas a partir do código-fonte do Semaphore**, portanto
descrevem a versão que você está executando, e não a versão para a qual alguém escreveu
uma tabela. Pelo mesmo motivo, elas são publicadas apenas em inglês: uma cópia traduzida
ficaria desatualizada na primeira vez que uma opção mudasse, e ninguém perceberia.
