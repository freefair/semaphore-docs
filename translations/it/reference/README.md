# Riferimento

Questa sezione serve nel momento in cui sai già che cosa vuoi e ti occorre il nome, il
tipo o il valore predefinito esatto. Spiega il meno possibile; a questo servono le guide.

Due delle pagine qui presenti sono **generate dal codice sorgente di Semaphore**, quindi
descrivono la versione che stai eseguendo e non quella per cui qualcuno aveva scritto una
tabella. Per lo stesso motivo sono pubblicate solo in inglese: una copia tradotta
sarebbe obsoleta al primo cambiamento di un'opzione, e nessuno se ne accorgerebbe.
