# リファレンス

このセクションは、何が必要かはすでに分かっていて、正確な名前・型・デフォルト値を知りたいときのためのものです。ここでの説明は最小限です。説明はガイドの役割です。

ここにあるページのうち 2 つは **Semaphore のソースコードから生成** されます。そのため、誰かが以前に表を書いたバージョンではなく、実際に動かしているバージョンを説明します。同じ理由から、これらのページは英語でのみ公開されます。翻訳したコピーは、オプションが一度変わっただけで古くなり、しかも誰も気づかないからです。

<a id="in-this-section"></a>

## このセクションの内容

| ページ | 扱う内容 |
|---|---|
| [設定オプション](../../../docs/reference/configuration.md) | `config.json` のすべてのキーと、その環境変数、型、デフォルト値。自動生成。 |
| [CLI](../../../docs/reference/cli/README.md) | `semaphore` コマンド。各コマンドグループの役割、設定ファイルの探索方法、そして自動生成されたすべてのコマンドとフラグの一覧。 |
| [API](../../../docs/reference/api.md) | トークンによる認証と、REST エンドポイントの呼び出し。 |
