# 設定

プロジェクトのダッシュボードの **設定** タブは、プロジェクトの **オーナー** が使用できます。ここにはプロジェクトの全般オプションと、破壊的な操作があります。

![プロジェクトの設定](../../../../static/assets/project-settings-general.webp)

<a id="general"></a>

## 全般

| フィールド | 説明 |
|---|---|
| **プロジェクト名** | プロジェクトの切り替えやアラートに表示される表示名です。 |
| **並列タスクの最大数** | 任意です。このプロジェクトのタスクを同時に実行できる最大数です。制限しない場合は空のままにします。制限を超えたタスクは、空きができるまで `waiting` のステータスでキューに残ります。 |
| **Telegram チャット ID** | 任意です。このプロジェクトのアラートを、グローバルに設定されたものとは別の Telegram チャットへ送信します。[Telegram 通知](../../../../docs/admin-guide/notifications/telegram.md#per-project-chat-ids)を参照してください。 |
| **このプロジェクトのアラートを許可する** | 通知の全体スイッチです。オフの場合、サーバーでチャネルが設定されていても、このプロジェクトのタスクに関するアラートはどのチャネルからも送信されません。 |

**アラートのテスト** は、設定済みのすべての[通知チャネル](../../../../docs/admin-guide/notifications.md)を通じてテストメッセージを送信するため、タスクを実行せずにサーバーの設定を確認できます。**保存** で変更が適用されます。

<a id="danger-zone"></a>

## 危険な操作

| 操作 | 効果 |
|---|---|
| **プロジェクトのバックアップ** | プロジェクトの定義（テンプレート、インベントリ、変数グループ、キー（シークレットの値は含まない）、リポジトリ、スケジュール、ビュー、インテグレーション）を含む JSON ファイルをダウンロードします。復元は **新しいプロジェクト → プロジェクトの復元** または [`semaphore projects import`](../../../../docs/reference/cli/projects.md) で行います。 |
| **キャッシュのクリア** | サーバー上にあるプロジェクトのキャッシュファイル（たとえばクローンしたリポジトリ）をすべて削除します。次のタスクでリポジトリが再度クローンされます。この操作は取り消せません。 |
| **プロジェクトの削除** | プロジェクトを、そのすべてのリソースとタスク履歴とともに削除します。取り消しはできません。 |
