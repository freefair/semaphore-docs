# 履歴

プロジェクトのダッシュボードの **履歴** タブには、プロジェクトのすべてのタスクが新しい順に一覧表示されます。プロジェクトを開いたときの既定のビューです。

![プロジェクトの履歴](../../../../static/assets/project-dashboard-history.webp)

<a id="columns"></a>

## 列

| 列 | 内容 |
|---|---|
| **タスク** | タスク番号、作成元のテンプレート、使用されたリポジトリのリビジョンのコミットメッセージです。左側のアイコンはアプリケーション（Ansible、Terraform、Bash など）を示します。 |
| **バージョン** | [ビルドおよびデプロイテンプレート](../task-templates/build-deploy.md)の場合は、ビルドまたはデプロイされたバージョンです。その他のテンプレートではステータスアイコンのみが表示されます。 |
| **ステータス** | 現在のステータスのバッジです。[タスクのステータス](../../../../docs/user-guide/tasks.md#task-statuses)を参照してください。 |
| **ユーザー** | タスクを開始したユーザーです。スケジュールやインテグレーションによって開始されたタスクにはユーザーがありません。 |
| **開始** | ブラウザーのタイムゾーンでの開始日時です。 |
| **所要時間** | タスクの実行にかかった時間です。 |

一覧はページ分割されます。タスク番号またはテンプレート名をクリックすると、ログ、詳細、サマリーを含む[タスクウィンドウ](../../../../docs/user-guide/tasks.md#task-window)が開きます。タスクウィンドウのヘッダーにあるテンプレート名をクリックすると、テンプレートのページに移動します。

<a id="task-retention"></a>

## タスクの保持

既定では、すべてのタスクとそのログは無期限に保持されます。テンプレートごとに履歴を制限するには、`config.json` で `max_tasks_per_template` を設定するか、環境変数 `SEMAPHORE_MAX_TASKS_PER_TEMPLATE` を設定します。

```json
{
  "max_tasks_per_template": 30
}
```

制限に達すると、そのテンプレートの最も古いタスクがログとともに削除されます。オプションの一覧は[設定](../../../../docs/admin-guide/configuration.md)を参照してください。
