# Guida utente

Scoprite come usare Semaphore nel lavoro quotidiano: creare progetti, eseguire attività, gestire inventory, chiavi, variabili e altro ancora.

## Da dove iniziare {#start-here}

- Organizzare il lavoro con progetti e team
- Collegare repository e key store
- Definire inventory e gruppi di variabili
- Creare template di attività ed eseguire attività in base a una pianificazione
