# Progetti

Un progetto è uno spazio in cui separare le attività di gestione.

Tutte le attività di Semaphore avvengono nel contesto di un progetto.

I progetti sono indipendenti l'uno dall'altro, quindi è possibile utilizzarli per organizzare sistemi non correlati all'interno di una singola installazione di Semaphore.

Questo può essere utile per gestire team, infrastrutture, ambienti o applicazioni diversi.
