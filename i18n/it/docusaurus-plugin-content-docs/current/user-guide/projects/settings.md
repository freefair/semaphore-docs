
# Impostazioni

La pagina Impostazioni consente di configurare vari aspetti del progetto, tra cui le notifiche e le impostazioni specifiche del progetto. Questa pagina è accessibile agli amministratori del progetto e offre una gestione centralizzata della configurazione del progetto.

![](/assets/project_settings.webp)

## Runner (Pro) {#runners-pro}

I runner di progetto possono essere collegati a un progetto. È inoltre possibile richiedere un runner specifico tramite tag in un modello:

1. In `Project → Runners`, aggiungere un runner e specificare un tag.
2. In `Project → Templates → <your template>`, impostare il tag del runner richiesto.

In questo modo il task viene eseguito su un runner corrispondente al tag.
