# Guía del usuario

Aprenda a usar Semaphore en el día a día: cree proyectos, ejecute tareas, gestione inventarios, claves, variables y mucho más.

## Empiece aquí {#start-here}

- Organice el trabajo con proyectos y equipos
- Conecte repositorios y el almacén de claves
- Defina inventarios y grupos de variables
- Cree plantillas de tareas y ejecute tareas de forma programada
