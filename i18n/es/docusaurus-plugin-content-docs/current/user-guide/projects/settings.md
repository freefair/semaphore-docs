
# Configuración

La página Configuración le permite ajustar varios aspectos de su proyecto, incluidas las notificaciones y los ajustes específicos del proyecto. Esta página es accesible para los administradores del proyecto y ofrece una gestión centralizada de la configuración del proyecto.

![](/assets/project_settings.webp)

## Runners (Pro) {#runners-pro}

Los runners de proyecto pueden asociarse a un proyecto. También puede exigir un runner concreto por etiqueta en una plantilla:

1. En `Project → Runners`, añada un runner y especifique una etiqueta.
2. En `Project → Templates → <your template>`, establezca la etiqueta de runner requerida.

Esto garantiza que la tarea se ejecute en un runner que coincida con la etiqueta.
