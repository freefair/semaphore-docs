# Proyectos

Un proyecto es un lugar para separar la actividad de gestión.

Todas las actividades de Semaphore ocurren en el contexto de un proyecto.

Los proyectos son independientes entre sí, por lo que puede usarlos para organizar sistemas no relacionados dentro de una única instalación de Semaphore.

Esto puede resultar útil para gestionar distintos equipos, infraestructuras, entornos o aplicaciones.
