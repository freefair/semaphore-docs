# Проекты

Проект — это способ разделить управленческую деятельность.

Все действия в Semaphore выполняются в контексте проекта.

Проекты независимы друг от друга, поэтому с их помощью можно организовать не связанные между собой системы в рамках одной установки Semaphore.

Это может быть полезно для управления разными командами, инфраструктурами, окружениями или приложениями.
