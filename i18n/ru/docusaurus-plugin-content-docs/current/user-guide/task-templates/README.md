# Шаблоны задач

Шаблоны определяют, как запускаются задачи Semaphore. В настоящее время поддерживаются следующие типы задач:

* [Ansible](/user-guide/apps/ansible)
* [Terraform/OpenTofu](/user-guide/apps/terraform)
* [Shell](/user-guide/apps/bash)
* [Powershell](/user-guide/apps/powershell)
* [Python](/user-guide/apps/python)

---

## Параллельные задачи {#parallel-tasks}

По умолчанию задачи одного шаблона выполняются последовательно. Чтобы разрешить одновременные запуски одного и того же шаблона, включите опцию «Allow parallel tasks» в настройках шаблона.

## Образ исполнителя (runner'ы Docker и Kubernetes) {#executor-image-docker-and-kubernetes-runners}

Когда runner проекта использует исполнитель **Docker** (Pro) или **Kubernetes** (Enterprise), каждая задача обычно выполняется в образе задания по умолчанию, настроенном на runner'е (например, `semaphoreui/job:latest`). Этот образ можно переопределить для каждого шаблона отдельно.

1. Откройте настройки шаблона
2. В поле **Executor image** укажите ссылку на образ контейнера (например, `my-registry/ansible:2.16` или `semaphoreui/job:latest`)
3. Сохраните шаблон

**Поведение**:
- Это поле учитывают только исполнители runner'а **Docker** и **Kubernetes**; локальный исполнитель его игнорирует
- Оставьте поле пустым, чтобы использовать образ runner'а по умолчанию из `runner.executor.docker.image` или `runner.executor.k8s.image`
- Очистка поля в интерфейсе удаляет переопределение

**Сценарии использования**:
- Шаблоны, которым нужен другой набор инструментов (более старая версия Ansible, конкретная версия Terraform, дополнительные пакеты ОС, встроенные в собственный образ)
- Изолированные образы для шаблонов, критичных с точки зрения безопасности, без изменения значения по умолчанию для всего runner'а

См. [Настройку runner'а](/admin-guide/configuration) для параметров образа по умолчанию и [Runner'ы проекта](/user-guide/projects/runners) для настройки исполнителя.
