# Задачи

Задача — это экземпляр запуска Ansible playbook. Создать задачу можно из [шаблона задачи](task-templates/), нажав кнопку Run/Build/Deploy для нужного шаблона.

![](/assets/image6.png)

Тип задачи **Deploy** позволяет указать версию сборки, связанной с задачей. По умолчанию это последняя версия сборки.

![](/assets/task_deploy1.png)

Пока задача выполняется или после её завершения вы можете видеть статус задачи и журнал выполнения.

![](/assets/image7.png)

### Просмотр необработанного журнала {#raw-log-view}

Необработанный журнал задачи можно открыть из окна журнала задачи с помощью действия RAW LOG.

## Хранение журналов задач {#tasks-log-retention}
Вы заметите, что журналы предыдущих запусков ваших задач доступны в шаблоне задач или на панели управления.

Однако по умолчанию журналы хранятся бессрочно.

Это можно настроить с помощью параметра `max_tasks_per_template` в `config.json` или переменной окружения `SEMAPHORE_MAX_TASKS_PER_TEMPLATE`.
