
# Рабочие пространства

Semaphore предоставляет встроенную поддержку рабочих пространств (workspaces) Terraform, позволяя управлять несколькими окружениями и конфигурациями в рамках одного проекта. Эта функция помогает хранить отдельные файлы состояния для разных окружений, таких как development, staging и production.

## Возможности {#features}

- **Управление рабочими пространствами**: создавайте, переключайте и удаляйте рабочие пространства прямо из Semaphore UI.
- **Изоляция состояния**: каждое рабочее пространство хранит собственный файл состояния, что предотвращает конфликты между окружениями.
- **Переменные окружения**: настраивайте переменные окружения для конкретного рабочего пространства.
- **Выбор рабочего пространства**: выбирайте целевое рабочее пространство при запуске команд Terraform.

## Использование рабочих пространств в Semaphore {#using-workspaces-in-semaphore}

### Создание рабочего пространства {#creating-a-workspace}

В разделе **Рабочие пространства** шаблона Terraform/OpenTofu, в который вы хотите добавить рабочее пространство, выполните следующие шаги:

1. Нажмите кнопку ➕.  
2. В появившемся меню выберите **Новое рабочее пространство**.  
3. В модальном окне введите имя рабочего пространства и выберите SSH-ключ, который будет использоваться для клонирования модулей.  
4. Нажмите кнопку **Создать**, чтобы добавить новое рабочее пространство в шаблон.  
5. Теперь вы можете использовать это рабочее пространство для запуска задач.


### Переключение рабочих пространств {#switching-workspaces}

Вы можете задать рабочее пространство по умолчанию для шаблона Terraform/OpenTofu, нажав кнопку **СДЕЛАТЬ ПО УМОЛЧАНИЮ**.


### Переменные для конкретного рабочего пространства {#workspace-specific-variables}

В настоящее время Semaphore не поддерживает переменные, привязанные к конкретному рабочему пространству.
