
# Shell/Bash-скрипты

Semaphore может выполнять shell-скрипты с помощью `/bin/bash`. Для этого создайте шаблон задачи **Bash Script**.

## Создание шаблона Bash {#creating-a-bash-template}

1. Перейдите в раздел **Шаблоны задач** и нажмите кнопку **Новый шаблон**.
2. Выберите **Bash** в качестве типа приложения.
3. Настройте шаблон:

| Поле | Описание |
|---|---|
| **Название** | Понятное название шаблона |
| **Репозиторий** | Репозиторий, содержащий ваш shell-скрипт |
| **Playbook / Скрипт** | Относительный путь к скрипту, например `scripts/deploy.sh` |
| **Группы переменных** | Группы переменных, значения которых передаются как переменные окружения |

4. Нажмите **Создать**.
5. Нажмите **Запустить**, чтобы выполнить шаблон.

## Передача переменных в скрипты {#passing-variables-to-scripts}

Переменные из выбранных **Групп переменных** передаются как переменные окружения. Обращайтесь к ним в скрипте через `$VARIABLE_NAME`:

```bash
#!/bin/bash
echo "Deploying to $TARGET_HOST"
```

## Примечания {#notes}

- Сделайте скрипт исполняемым (`chmod +x`) или убедитесь, что он начинается с корректного shebang (`#!/bin/bash`).
- Скрипты выполняются в неинтерактивном режиме. Избегайте запросов, ожидающих ввода пользователя.
- Код выхода `0` означает успех; любой ненулевой код выхода помечает задачу как неудачную.
- Если очень короткий скрипт не выводит ничего в лог, см. [Вывод Bash-скрипта отсутствует или неполный](/admin-guide/troubleshooting#bash-script-output-is-missing-or-incomplete) в руководстве по устранению неполадок.
- Для выполнения команд на удалённых хостах используйте [Ansible](./ansible).
