# Настройки

Страница «Настройки» позволяет настраивать различные аспекты вашего проекта, включая уведомления и параметры, специфичные для проекта. Эта страница доступна администраторам проекта и обеспечивает централизованное управление конфигурацией проекта.

![](/assets/project_settings.webp)

## Раннеры (Pro) {#runners-pro}

Раннеры проекта можно привязать к проекту. Вы также можете потребовать использование конкретного раннера по тегу в шаблоне:

1. В `Project → Runners` добавьте раннер и укажите тег.
2. В `Project → Templates → <your template>` задайте требуемый тег раннера.

Это гарантирует, что задача будет выполнена на раннере с соответствующим тегом.
