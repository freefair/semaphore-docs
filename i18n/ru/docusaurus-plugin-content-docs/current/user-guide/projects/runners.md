
# Раннеры проекта (Pro)

Раннеры проекта — это мощная функция Semaphore Pro, которая позволяет распределённо выполнять задачи на нескольких серверах. Она даёт возможность запускать задачи на серверах, отдельных от вашего экземпляра Semaphore UI, обеспечивая повышенную безопасность, масштабируемость и управление ресурсами.

![](/assets/project_runners.webp)

## Обзор {#overview}

Раннеры проекта работают по тому же принципу, что и раннеры GitLab или GitHub Actions:

- Раннер разворачивается на сервере, отдельном от вашего Semaphore UI
- Раннер подключается к вашему экземпляру Semaphore с помощью защищённого токена
- При создании задач Semaphore делегирует их доступным раннерам
- Раннеры выполняют задачи и отправляют результаты обратно в Semaphore

## Преимущества {#benefits}

Использование раннеров даёт несколько ключевых преимуществ:

1. **Повышенная безопасность**
   - Раннеры можно разворачивать в изолированных средах или сетях с ограниченным доступом
   - Чувствительные операции можно выполнять в контролируемых средах
   - Лучшее разделение ответственности между интерфейсом и средой выполнения

2. **Улучшенная масштабируемость**
   - Распределение нагрузки между несколькими серверами
   - Добавление и удаление раннеров в зависимости от спроса
   - Более эффективное использование ресурсов вашей инфраструктуры

3. **Гибкое развёртывание**
   - Размещайте раннеры ближе к целевой инфраструктуре
   - Запускайте задачи в разных сетевых зонах
   - Поддержка различных моделей развёртывания (on-premises, облако, гибрид)

## Использование раннеров проекта {#using-project-runners}

### Предварительные требования {#prerequisites}

Для использования раннеров вам понадобятся:

1. Лицензия Semaphore Pro
2. Отдельный сервер для запуска раннера
3. Сетевая связность между раннером и Semaphore UI
4. Корректная настройка как на сервере Semaphore UI, так и на сервере раннера

### Управление раннерами {#managing-runners}

Управлять раннерами можно через Semaphore UI:

1. Перейдите в раздел «Раннеры» вашего проекта
2. Просмотрите все зарегистрированные раннеры и их статус
3. Добавляйте или удаляйте раннеры по мере необходимости
4. Отслеживайте состояние и производительность раннеров

### Вопросы безопасности {#security-considerations}

- Всегда используйте HTTPS для взаимодействия между раннерами и Semaphore UI
- Обеспечьте надлежащую сетевую безопасность между раннерами и Semaphore UI
- Рассмотрите использование изолированных сред для чувствительных операций

## Рекомендации {#best-practices}

1. **Планирование ресурсов**
   - Подбирайте размер раннеров в соответствии с нагрузкой
   - Отслеживайте использование ресурсов раннерами
   - Масштабируйте раннеры в зависимости от спроса

2. **Настройка сети**
   - Обеспечьте надлежащую сетевую связность
   - Правильно настройте межсетевые экраны
   - Используйте защищённые каналы связи

3. **Обслуживание**
   - Регулярно обновляйте программное обеспечение раннеров
   - Отслеживайте состояние раннеров
   - Настройте надлежащее логирование и мониторинг
   - Подготовьте стратегию резервирования на случай отказа раннеров

4. **Безопасность**
   - Следуйте принципу наименьших привилегий
   - Настройте надлежащий контроль доступа
   - Регулярно проводите аудит безопасности
   - Поддерживайте программное обеспечение в актуальном состоянии
