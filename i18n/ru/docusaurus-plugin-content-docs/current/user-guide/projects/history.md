
# История

Экран «История» в Semaphore предоставляет полное представление обо всех запусках задач в вашем проекте. Эта функция позволяет отслеживать и анализировать историю выполнения задач, давая ценную информацию о ваших процессах автоматизации.

![](/assets/project_history.webp)

## Обзор {#overview}

Страница «История» отображает хронологический список всех запусков задач, включая:

- Использованные шаблоны задач
- Статус выполнения (успех, ошибка, в процессе)
- Время начала и окончания
- Длительность
- Пользователя, запустившего задачу
- Вывод и логи задачи

## Просмотр истории задач {#viewing-task-history}

### Доступ к истории {#accessing-history}

1. Перейдите в свой проект в Semaphore
2. Откройте вкладку «История»
3. Просмотрите список всех запусков задач

## Детали задачи {#task-details}

Нажатие на любую задачу в списке истории открывает подробное представление, содержащее:

1. **Информацию о задаче**
   - ID задачи
   - Использованный шаблон
   - Время начала и окончания
   - Длительность
   - Статус
   - Пользователя, запустившего задачу

2. **Детали выполнения**
   - Полный вывод задачи
   - Сообщения об ошибках (если есть)
   - Использованные переменные окружения
   - Информацию об инвентаре
   - Сведения о репозитории

3. **Логи задачи**
   - Просмотр логов в реальном времени
   - Возможность скачать логи
   - Поиск по логам
   - Подсветку ошибок

### Статистика {#statistics}

В проекте есть страница статистики, которая обобщает результаты задач за выбранный период с фильтрацией по пользователю.

## Управление задачами {#task-management}

### Доступные действия {#actions-available}

Из представления истории вы можете:

- Открыть полные логи задачи
- Скачать вывод задачи
- Выполнить поиск по логам

## Хранение истории задач {#task-retention}

Semaphore позволяет настроить, как долго хранится история задач:

1. **Поведение по умолчанию**
   - Все задачи сохраняются в базе данных
   - По умолчанию автоматическое удаление не выполняется

2. **Настройка хранения**
   - Задайте максимальное количество задач на шаблон
   - Через переменную окружения:
     ```bash
     SEMAPHORE_MAX_TASKS_PER_TEMPLATE=30
     ```
   - Или через config.json:
     ```json
     {
       "max_tasks_per_template": 30
     }
     ```

3. **Правила хранения**
   - При достижении лимита самые старые задачи удаляются автоматически
   - Удаление выполняется отдельно для каждого шаблона
   - Логи задач удаляются вместе с записями о задачах
