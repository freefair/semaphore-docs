# インテグレーション

インテグレーションを使用すると、Semaphore と GitHub や GitLab などの外部サービスとの連携を確立できます。

![](/assets/integrations_1.jpg)

インテグレーションを使用すると、特別なエンドポイント (エイリアス) を呼び出すことで特定のテンプレートをトリガーできます。このエンドポイントには、次のいずれかの認証方法を設定できます。
* GitHub Webhooks
* トークン
* HMAC
* 認証なし

エイリアスは `/api/integrations/<random_string>` という形式の URL です。`GET` および `POST` リクエストをサポートしています。

## マッチャー {#matchers}

マッチャーを使用すると、受信リクエストのパラメーターを定義できます。これらのパラメーターが一致すると、テンプレートが呼び出されます。

## 値エクストラクター {#value-extractors}

エクストラクターを使用すると、受信リクエストから必要なデータを抽出し、環境変数としてタスクに渡すことができます。抽出した変数をタスクに渡すには、
対応するキーを持つ環境を作成する必要があります。タスクが正しい環境変数を受け取って使用できるように、
環境のキーがエクストラクターで定義した変数と一致していることを確認してください。

## タスクパラメーター {#task-parameters}

インテグレーションはパラメーター付きでタスクをトリガーできます。値エクストラクターを使用してタスクパラメーター用の JSON ペイロードを構築し、プロンプトで入力される値を受け付けるようにテンプレートを設定してください。

## エイリアスとマッチャーに関する注意 {#notes-on-aliases-and-matchers}

エイリアスエンドポイントで設定されたインテグレーションでは、マッチャーは使用されません。必要に応じてトークン/HMAC 認証を優先し、パラメーターはエクストラクター経由で渡してください。
