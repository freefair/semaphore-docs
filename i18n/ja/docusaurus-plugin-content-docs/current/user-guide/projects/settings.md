
# 設定

設定ページでは、通知やプロジェクト固有の設定など、プロジェクトのさまざまな側面を設定できます。このページはプロジェクト管理者がアクセスでき、プロジェクト設定を一元的に管理できます。

![](/assets/project_settings.webp)

## Runner (Pro) {#runners-pro}

プロジェクト runner をプロジェクトに関連付けることができます。また、テンプレートでタグにより特定の runner を必須にすることもできます。

1. `Project → Runners` で runner を追加し、タグを指定します。
2. `Project → Templates → <your template>` で、必要な runner のタグを設定します。

これにより、タスクはタグに一致する runner で実行されるようになります。
