
# Einstellungen

Auf der Seite Einstellungen können Sie verschiedene Aspekte Ihres Projekts konfigurieren, darunter Benachrichtigungen und projektspezifische Einstellungen. Diese Seite ist für Projektadministratoren zugänglich und bietet eine zentrale Verwaltung der Projektkonfiguration.

![](/assets/project_settings.webp)

## Runner (Pro) {#runners-pro}

Projekt-Runner können einem Projekt zugeordnet werden. Sie können in einer Vorlage außerdem einen bestimmten Runner anhand eines Tags vorschreiben:

1. Fügen Sie unter `Project → Runners` einen Runner hinzu und geben Sie ein Tag an.
2. Legen Sie unter `Project → Templates → <your template>` das erforderliche Runner-Tag fest.

Dadurch wird sichergestellt, dass die Aufgabe auf einem Runner ausgeführt wird, der dem Tag entspricht.
