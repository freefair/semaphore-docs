# Projekte

Ein Projekt ist ein Ort, um Verwaltungsaktivitäten voneinander zu trennen.

Alle Aktivitäten in Semaphore finden im Kontext eines Projekts statt.

Projekte sind voneinander unabhängig, sodass Sie mit ihnen nicht zusammenhängende Systeme innerhalb einer einzigen Semaphore-Installation organisieren können.

Das ist nützlich für die Verwaltung verschiedener Teams, Infrastrukturen, Umgebungen oder Anwendungen.
