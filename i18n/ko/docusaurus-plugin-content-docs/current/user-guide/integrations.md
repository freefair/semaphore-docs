# 통합

통합을 사용하면 Semaphore와 GitHub, GitLab 같은 외부 서비스 간의 상호 작용을 설정할 수 있습니다.

![](/assets/integrations_1.jpg)

통합을 사용하면 특수 엔드포인트(별칭)를 호출하여 특정 템플릿을 트리거할 수 있으며, 이에 대해 다음 인증 방법 중 하나를 구성할 수 있습니다:
* GitHub Webhooks
* Token
* HMAC
* 인증 없음

별칭은 다음 형식의 URL을 나타냅니다: `/api/integrations/<random_string>`. `GET` 및 `POST` 요청을 지원합니다.

## 매처 {#matchers}

매처를 사용하면 들어오는 요청의 매개변수를 정의할 수 있습니다. 이 매개변수가 일치하면 템플릿이 호출됩니다.

## 값 추출기 {#value-extractors}

추출기를 사용하면 들어오는 요청에서 필요한 데이터를 추출하여 환경 변수로 작업에 전달할 수 있습니다. 추출된 변수를 작업에 전달하려면
해당 키를 가진 환경을 생성해야 합니다. 환경 키가 추출기에 정의된 변수와 일치하는지 확인하십시오. 그래야 작업이 올바른 환경 변수를
받아 사용할 수 있습니다.

## 작업 매개변수 {#task-parameters}

통합은 매개변수와 함께 작업을 트리거할 수 있습니다. 값 추출기를 사용하여 작업 매개변수용 JSON 페이로드를 구성하고, 템플릿이 프롬프트 값을 받도록 구성하십시오.

## 별칭 및 매처에 대한 참고 사항 {#notes-on-aliases-and-matchers}

별칭 엔드포인트로 구성된 통합에서는 매처가 사용되지 않습니다. 필요에 따라 token/HMAC 인증을 사용하고 추출기를 통해 매개변수를 전달하십시오.
