# 소개

Semaphore UI 관리자 가이드에 오신 것을 환영합니다. 이 가이드는 Semaphore 인스턴스의 설치, 구성, 유지 보수에 관한 포괄적인 정보를 제공합니다.

## Semaphore UI란? {#what-is-semaphore-ui}

Semaphore UI는 자동화 태스크를 실행하기 위한 현대적인 오픈 소스 웹 인터페이스입니다. 더 복잡한 자동화 플랫폼에 대한 가볍고 빠르며 사용하기 쉬운 대안으로 설계되었습니다.

다음 태스크를 안전하게 관리하고 실행할 수 있습니다.
*   **Ansible** playbook
*   **Terraform/OpenTofu** 코드형 인프라
*   **PowerShell** 및 **Shell** 스크립트
*   **Python** 스크립트

## 핵심 기능 및 철학 {#core-features--philosophy}

Semaphore의 설계 원칙을 이해하면 Semaphore를 최대한 활용하는 데 도움이 됩니다.

*   **가볍고 뛰어난 성능**: Semaphore는 **Go**로 작성되었으며 **단일 바이너리 파일**로 배포됩니다. 최소한의 리소스(CPU/RAM)만 필요하며 Kubernetes, Docker, JVM 같은 외부 의존성이 필요하지 않습니다. 덕분에 빠르고 효율적이며 배포하기 쉽습니다.
*   **간단한 설치 및 유지 보수**: 몇 분 만에 Semaphore를 실행할 수 있습니다. 설치는 바이너리를 다운로드하여 실행하는 것만으로 충분할 수 있습니다. 단순한 아키텍처 덕분에 업그레이드와 유지 보수가 간단합니다.
*   **유연한 배포**: 바이너리, systemd 서비스 또는 Docker 컨테이너로 실행할 수 있습니다. 개인 홈랩부터 엔터프라이즈 환경까지 모든 곳에 적합합니다.
*   **자체 호스팅 및 보안**: Semaphore는 자체 호스팅 솔루션입니다. 모든 데이터, 자격 증명, 로그가 자체 인프라에 남아 있으므로 완전한 제어권을 가질 수 있습니다. 자격 증명은 데이터베이스에 항상 암호화되어 저장됩니다.
*   **강력한 통합**: 단순하지만 Semaphore는 LDAP/OpenID 인증, 프로젝트별 세분화된 역할 기반 접근 제어(RBAC), 태스크 실행 확장을 위한 원격 runner, 프로그래밍 방식 접근을 위한 완전한 REST API 같은 강력한 기능을 지원합니다.

이 가이드는 필요에 맞게 이러한 기능을 설정하고 관리하는 방법을 안내합니다.
