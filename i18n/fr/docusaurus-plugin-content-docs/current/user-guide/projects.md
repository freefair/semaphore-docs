# Projets

Un projet est un espace permettant de cloisonner les activités de gestion.

Toutes les activités de Semaphore se déroulent dans le contexte d'un projet.

Les projets sont indépendants les uns des autres ; vous pouvez donc les utiliser pour organiser des systèmes sans lien entre eux au sein d'une même installation de Semaphore.

Cela peut être utile pour gérer différentes équipes, infrastructures, environnements ou applications.
