
# Paramètres

La page Paramètres vous permet de configurer différents aspects de votre projet, notamment les notifications et les paramètres propres au projet. Cette page est accessible aux administrateurs du projet et offre une gestion centralisée de la configuration du projet.

![](/assets/project_settings.webp)

## Runners (Pro) {#runners-pro}

Des runners de projet peuvent être rattachés à un projet. Vous pouvez également exiger un runner spécifique par tag dans un modèle :

1. Dans `Project → Runners`, ajoutez un runner et indiquez un tag.
2. Dans `Project → Templates → <your template>`, définissez le tag de runner requis.

Cela garantit que la tâche est exécutée sur un runner correspondant à ce tag.
