# State backend availability

The built-in Terraform HTTP state backend and its aliases are not implemented in Semaphore EX.
Configure a backend supported by Terraform or OpenTofu in your infrastructure code.
See [Terraform and OpenTofu](./README.md) for running tasks with that backend.
