# Reference

This section is for the moment you already know what you want and need the exact
name, type, or default. It explains as little as possible; the guides do that.

Configuration, CLI and API references here are **generated from the Semaphore source code**, so they describe the checked-in source revision.
Use the documentation revision matching your deployed release. For the same reason they are published in English only: a translated copy would
go stale the first time an option changed, and nobody would notice.
